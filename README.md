# 📱 Mobile-Friendly Event Page

A responsive event website built using **HTML** and **CSS**.  
This project demonstrates how to convert a desktop layout into a mobile-friendly design using **CSS Media Queries**.

---

## 🚀 Features

- Responsive layout using media queries
- Sticky navigation bar
- Mobile-friendly typography
- Responsive images and sections
- Smooth scrolling navigation
- Clean modern UI design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Media Queries
- Chrome DevTools (for testing)
